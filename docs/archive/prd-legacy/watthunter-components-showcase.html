Decision Summary
Visual distinction rules
ComponentShapeRadiusInteractiveKey visual cue
Underline Tab Text only — ✅ Navigation Cyan underline on active
Filter Chip Squared pill 6px ✅ Filter/Switch Bg fill on active, squared corners
Tag Round pill 20px ❌ Display only Full pill, color-coded by variant
1
Radius = affordance signal. 20px pill = decorative (tag, not clickable). 6px squared = functional (filter, clickable). The shape alone tells the user what's interactive.
2
Tags have 4 color variants (default, highlighted, success, warning) but share identical sizing. The locked state is NOT a tag variant — it's a row-level opacity:0.4 applied to the parent.
3
Filter chips have 2 layout variants: Contained (with bg-surface container) for tight UIs, and Free (individual borders) for sections with more space. Same tokens, different wrapper.
